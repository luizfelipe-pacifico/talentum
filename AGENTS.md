# Agent Instructions

The rules for every AI coding agent working in this repository (Codex, Claude Code and any other) live in [`CLAUDE.md`](./CLAUDE.md). Read it in full before doing anything and follow it exactly: every rule there binds you as it binds Claude Code, including the reading list, the security gate before commit and push, test-first bug fixes and the self-review loop.

This file deliberately contains nothing else, so the two files can never diverge. Do not copy rules here; when the user gives a standing instruction ("sempre…", "always…"), record it in `CLAUDE.md` only.

Where `CLAUDE.md` names a Claude-specific tool (for example the Claude in Chrome extension), use the equivalent capability you have, or say in your report that you could not perform that step.
